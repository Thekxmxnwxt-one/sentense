# นักสืบพิชิตประโยคความเดียว

เกมห้องเรียนแบบหลายผู้เล่นสำหรับฝึกประโยคความเดียวระดับ ม.4 สร้างด้วย Go และ React TypeScript มีห้องรหัส 5 ตัว อัปเดตเรียลไทม์ คะแนนสะสม การเล่นพร้อมกัน และแดชบอร์ดครูสำหรับแชร์หน้าจอ

## เกมและด่านระดับ ม.4

ผู้เล่นทุกคนเล่นเรียงครบทั้ง 5 ด่านในทัวร์นาเมนต์เดียว คะแนนส่วนตัวสะสมข้ามด่าน และระบบสรุปโพเดียมอันดับ 1–2–3 จากคะแนนรวมเมื่อจบด่านสุดท้าย

1. **ห้องหลบหนี 5 กุญแจ** — ร่วมกันไขรหัสพื้นฐานและปลดล็อกกุญแจความรู้ทั้ง 5 ดอก
2. **ห้องแล็บจับคู่** — จับคู่ภาคประธาน ภาคแสดง กรรม และส่วนขยาย
3. **สภาโหวตประโยค** — ทุกคนโหวตหมวดความเดียว–รวม–ซ้อนและดูผลโหวตพร้อมกัน
4. **คลินิกซ่อมประโยค** — เลือกวิธีแก้ส่วนขาด ความกำกวม และลดใจความ
5. **โรงงานต่อแถบคำ** — เลือกและเรียงแถบคำให้เป็นประโยคที่ชัดเจน

ทุกด่านมีความรู้สอดแทรกและคำอธิบายหลังตอบ โดยระบบตรวจคะแนนให้อัตโนมัติทั้งหมด

## เริ่มใช้งาน

ต้องมี Go 1.26+ และ Node.js 20+

```bash
cd frontend
pnpm install
pnpm build
cd ../backend
go run ./cmd/server
```

เปิด `http://localhost:8080` บนอุปกรณ์ของครู แล้วเลือก **สร้างห้อง** นักเรียนที่อยู่ในเครือข่ายเดียวกันเปิด `http://<IP-เครื่องครู>:8080` และกรอกรหัสห้อง

สำหรับพัฒนาหน้าเว็บแบบ hot reload ให้เปิดสอง terminal:

```bash
cd backend && go run ./cmd/server
cd frontend && pnpm dev
```

จากนั้นเปิด `http://localhost:5173`

## วิธีเล่น

- รองรับ 2–12 คนต่อห้อง หัวหน้าห้องเป็นผู้เริ่มเกม
- ครูเป็นผู้สร้างห้องและแชร์แดชบอร์ด ไม่ถูกนับเป็นผู้แข่งขัน
- ครูเห็นแดชบอร์ดคะแนน จำนวนครั้งที่ตอบ จำนวนข้อถูก และจำนวนรอบที่ชนะของนักเรียนทุกคนแบบสด
- เมื่อนักเรียนเข้าคนแรก ระบบนับ 30 วินาที (เริ่มนับใหม่เมื่อมีคนเข้าเพิ่ม) แล้วเริ่มทัวร์นาเมนต์เอง
- ระบบเปิดโจทย์ นับถอยหลัง ตรวจคะแนน แสดงผู้ชนะ และเปลี่ยนข้อ/ด่านอัตโนมัติแบบ Kahoot
- หน้าครูออกแบบสำหรับแชร์ขึ้นจอหน้าห้อง ไม่มีปุ่มควบคุมหรือตรวจคำตอบ
- นักเรียนทุกคนเห็นโจทย์พร้อมกัน ผู้ตอบถูกคนแรกได้ 3 คะแนน ผู้ตอบถูกภายหลังได้ 1 คะแนน
- รูปแบบแต่ละด่านต่างกัน ได้แก่ เลือกประตู จับคู่ โหวตร่วมกัน ซ่อมประโยค และต่อแถบคำ
- ทุกคำตอบตรวจคะแนนอัตโนมัติ
- ตอบถูกช่วยเพิ่มทั้งคะแนนส่วนตัวและดาวทีม
- แต่ละด่านจบเมื่อมีผู้เล่นถึงช่อง 24 หรือครบ 12 รอบ จากนั้นเข้าสู่เกมถัดไปอัตโนมัติโดยคงคะแนนเดิม
- เมื่อครบ 5 ด่าน ระบบเรียงคะแนนรวมและแสดงโพเดียมอันดับ 1–2–3

## ตรวจสอบ

```bash
cd backend && go test ./...
cd frontend && pnpm build
```

Backend ใช้เฉพาะ Go standard library และเก็บห้องไว้ในหน่วยความจำ จึงเหมาะกับการเปิดใช้ในชั้นเรียนทันทีโดยไม่ต้องตั้งฐานข้อมูล เมื่อปิดเซิร์ฟเวอร์ข้อมูลห้องจะถูกล้าง
